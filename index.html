FAQ

Wichtige Fragen.

Brauche ich Minecraft Java gekauft?

Ja. NYRITH ist für legitime Minecraft Java Edition Accounts gedacht und enthält keine Minecraft-Spieldateien als Ersatz für einen Kauf.

Brauche ich Java selbst zu installieren?

Normalerweise nicht. NYRITH kann für unterstützte Minecraft-Versionen automatisch die passende Java-Hauptversion vorbereiten.

Kann ich meine eigenen Mods benutzen?

Ja. Du kannst kompatible Mods aus der Library installieren oder lokale .jar-Dateien direkt in eine Instance importieren.

Muss ich für jedes Update neu downloaden?

Nein. Sobald der öffentliche Release-Kanal verbunden ist, prüft NYRITH selbst auf neue Releases und kann Updates direkt im Client laden und installieren.
