FAQ

Noch Fragen?

Die wichtigsten Sachen bevor du NYRITH installierst.

Brauche ich Minecraft Java gekauft?+

Ja. NYRITH ist für legitime Minecraft Java Edition Accounts gedacht und ersetzt keinen Minecraft-Kauf.

Muss ich Java selbst installieren?+

Für unterstützte Versionen kann NYRITH automatisch die passende Java-Hauptversion vorbereiten.

Kann ich meine eigenen Mods benutzen?+

Ja. Du kannst Mods über die Library installieren oder lokale kompatible .jar-Dateien direkt in eine Instance importieren.

Muss ich Updates immer neu herunterladen?+

Der Client besitzt einen integrierten Updater. Sobald der öffentliche Release-Kanal vollständig verbunden ist, können neue Builds direkt aus NYRITH geladen und installiert werden.

Ist NYRITH schon fertig?+

Nein. NYRITH befindet sich aktuell in einer Alpha-Phase. Features und Kompatibilität werden weiter ausgebaut.
